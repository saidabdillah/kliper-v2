# Tahap 1

Gunakan satu proses Uvicorn dan satu tugas media berat sekaligus. File unggahan ditulis secara streaming, diperiksa FFprobe dan dinormalisasi sebelum ditampilkan. Metadata dan keputusan edit disimpan per proyek, terpisah dari video sumber. Waktu layer memakai detik relatif pada hasil potongan. FFmpeg menyusun B-roll dan mencampur musik sebelum menanam subtitle dan menghasilkan MP4.
